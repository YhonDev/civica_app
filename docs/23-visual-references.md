# VigiVecino
## Visual References & Design Direction

Version: 1.0

Platform: Flutter

Target Year: 2026

---

# Objetivo

Este documento define la dirección artística de VigiVecino.

No describe componentes.

No describe pantallas.

No describe lógica.

Describe cómo debe verse y sentirse toda la aplicación.

Este documento sirve como guía para cualquier diseñador o agente de IA encargado de construir la interfaz.

Toda decisión visual debe alinearse con estas referencias.

---

# Filosofía

VigiVecino debe sentirse como un producto premium.

No como un software administrativo.

No como un sistema contable.

No como un ERP.

Debe transmitir la sensación de una aplicación moderna creada específicamente para dispositivos móviles.

Debe parecer una aplicación que cualquier usuario estaría orgulloso de instalar y utilizar diariamente.

---

# Personalidad

La aplicación debe sentirse:

- Moderna
- Elegante
- Profesional
- Limpia
- Rápida
- Confiable
- Minimalista
- Inteligente

Nunca debe sentirse:

- Anticuada
- Empresarial
- Sobrecargada
- Infantil
- Colorida en exceso
- Llena de tablas
- Llena de formularios

# Diseño General

La aplicación debe utilizar grandes espacios en blanco.

Las tarjetas deben respirar.

El usuario nunca debe sentirse encerrado.

La información debe aparecer agrupada.

Nunca comprimida.

---

# Tarjetas

Las tarjetas son el componente principal.

Nunca deben parecer cajas.

Deben sentirse como superficies flotantes.

Con bordes suaves.

Sombras mínimas.

Mucho espacio interno.

Cada tarjeta responde una pregunta.

Nunca dos.

---

# Dashboard

El Dashboard no es un menú.

Es un resumen inteligente.

Debe permitir entender el estado general en menos de cinco segundos.

Toda información secundaria pertenece a otros módulos.

---

# Gráficos

Los gráficos deben ser extremadamente simples.

Priorizar.

Línea.

Barras.

Área.

Nunca.

Pastel.

Radar.

3D.

Donas complejas.

---

# Iconografía

Iconos modernos.

Outlined.

Consistentes.

Sin mezclar estilos.

Cada icono debe tener un propósito claro.

---

# Colores

El color comunica estados.

Nunca decoración.

Verde

Correcto.

Rojo

Mora.

Amarillo

Pendiente.

Azul

Información.

Gris

Secundario.

Nunca utilizar colores aleatorios.

---

# Espaciado

Mucho aire.

Mucho margen.

Mucho padding.

La aplicación debe sentirse relajada.

Nunca comprimida.

---

# Formularios

Los formularios deben sentirse ligeros.

Pocos campos visibles.

Asistentes cuando sea necesario.

Nunca formularios gigantes.

---

# Botones

Debe existir siempre una acción principal.

Una secundaria.

Nada más.

Nunca cinco botones importantes en una misma pantalla.

---

# Navegación

Toda navegación debe sentirse natural.

Nunca obligar al usuario a recordar dónde está algo.

La aplicación debe guiarlo.

---

# Información

La información importante siempre aparece arriba.

La secundaria debajo.

La histórica bajo demanda.

Nunca mostrar todo desde el inicio.

---

# Dashboard del Administrador

Debe sentirse como un centro ejecutivo.

No como un panel administrativo.

Debe priorizar.

Indicadores.

Gráficos.

Resumen.

Actividad.

No CRUD.

---

# Dashboard del Cobrador

Debe sentirse como una herramienta de trabajo.

Todo orientado a la velocidad.

Registrar pagos.

Buscar propietarios.

Consultar viviendas.

Nada más.

---

# Dashboard del Propietario

Debe sentirse como una aplicación bancaria.

Muy limpia.

Muy clara.

Debe transmitir tranquilidad.

El propietario debe entender inmediatamente si está al día o tiene pagos pendientes.

---

# Ticket Digital

Debe sentirse como un comprobante moderno.

Inspiración.

Apple Wallet.

Google Wallet.

No como una factura impresa.

Debe ser limpio.

Compacto.

Legible.

---

Inspiración.

---

# Animaciones

Inspiración.

Apple.

Material 3.

Arc.

Nunca protagonizan.

---

# Lo que se debe evitar

No usar.

Tablas gigantes.

Menús interminables.

Fondos con imágenes.

Gradientes exagerados.

Sombras fuertes.

Botones pequeños.

Muchos colores.

Pantallas llenas de texto.

Listados infinitos.

Formularios de veinte campos.

Drawer lateral como navegación principal.

Diseños que parezcan aplicaciones de escritorio.

---

# Lo que sí queremos

Pantallas limpias.

Tarjetas modernas.

Espacios amplios.

Microinteracciones.

Feedback inmediato.

Carga progresiva.

Diseño consistente.

Responsive.

Modo oscuro.

Accesibilidad.

Animaciones suaves.

---

# Objetivo Final

Si una persona abre VigiVecino por primera vez debe pensar:

"Esta aplicación se siente moderna, rápida y profesional."

Nunca debe pensar:

"Esto parece un sistema administrativo antiguo."

Toda decisión visual debe acercar la aplicación a una experiencia premium comparable con las mejores aplicaciones móviles de 2026.
